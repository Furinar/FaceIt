# FaceIt 用户手册

## 一、产品简介

### 1.1 产品概述

FaceIt 是一款面向计算机相关专业学生的 AI 模拟面试与能力提升平台。通过 AI 技术模拟真实面试场景，提供多维度智能评估与反馈，帮助学生提升面试技巧，增强就业竞争力。

### 1.2 核心功能

- **模拟面试**：AI 面试官模拟真实面试流程
- **智能评估**：多维度分析回答质量
- **即时反馈**：每道题回答后即时获取反馈
- **成长追踪**：记录面试历史，展示能力成长曲线
- **智能推荐**：根据薄弱点推荐练习内容

### 1.3 适用人群

- 计算机相关专业大学生
- 准备求职的应届毕业生
- 希望提升面试技巧的技术人员

## 二、快速开始

### 2.1 注册账号

1. 访问 FaceIt 网站
2. 点击右上角「注册」按钮
3. 输入用户名、密码
4. 点击「注册」完成账号创建

![注册页面](./images/register.png)

### 2.2 登录系统

1. 点击右上角「登录」按钮
2. 输入用户名和密码
3. 点击「登录」进入系统

### 2.3 开始面试

1. 登录后进入「面试大厅」
2. 选择目标岗位（如 Java 后端工程师）
3. 选择面试模式和难度
4. 点击「开始面试」

## 三、功能详解

### 3.1 面试大厅

面试大厅是系统的首页，展示以下内容：

| 区域 | 说明 |
|------|------|
| 岗位选择 | 选择要面试的岗位类型 |
| 面试模式 | 选择自由练习/模拟面试/专项突破 |
| 难度选择 | 选择初级/中级/高级 |
| 历史记录 | 查看最近的面试记录 |

#### 面试模式说明

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 自由练习 | 自主选择题目类型练习 | 针对性提升 |
| 模拟面试 | AI 主导完整面试流程 | 模拟真实面试 |
| 专项突破 | 针对特定知识点强化 | 薄弱点突破 |

### 3.2 模拟面试

#### 3.2.1 面试流程

```
开始面试 → AI提问 → 用户回答 → 即时反馈 → (追问) → 下一题 → ... → 结束面试 → 查看报告
```

#### 3.2.2 回答方式

**文字回答：**
1. 在输入框中输入回答内容
2. 点击「提交」按钮

**语音回答：**
1. 点击「语音输入」按钮
2. 对着麦克风说出回答
3. 点击「停止」完成录音
4. 系统自动识别并提交

#### 3.2.3 智能追问

当你的回答存在以下情况时，AI 会进行追问：

- 回答不够完整
- 关键点未覆盖
- 可以深入展开

追问示例：
```
AI：请介绍一下 HashMap 的底层实现原理。
用户：HashMap 底层是数组加链表的结构...
AI：你提到了 HashMap 不是线程安全的，那么在多线程场景下应该使用什么替代方案？
```

### 3.3 评估报告

#### 3.3.1 报告内容

面试结束后，系统自动生成评估报告，包含：

| 内容 | 说明 |
|------|------|
| 综合得分 | 本次面试的总分（百分制） |
| 维度得分 | 技术正确性、知识深度、逻辑严谨性、岗位匹配度 |
| 亮点分析 | 回答中的亮点和优势 |
| 不足分析 | 回答中的不足和问题 |
| 改进建议 | 具体的改进建议 |
| 推荐练习 | 针对薄弱点的推荐题目 |

#### 3.3.2 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 技术正确性 | 30% | 回答的技术内容是否正确 |
| 知识深度 | 25% | 对知识点的理解深度 |
| 逻辑严谨性 | 20% | 回答的逻辑是否清晰 |
| 岗位匹配度 | 25% | 回答是否符合岗位要求 |

### 3.4 成长中心

#### 3.4.1 面试历史

查看所有面试记录，包括：

- 面试时间
- 岗位类型
- 面试模式
- 得分
- 状态

#### 3.4.2 成长曲线

可视化展示能力成长趋势：

- 总分趋势
- 各维度得分趋势
- 技能点掌握情况

#### 3.4.3 智能推荐

系统根据你的薄弱点推荐：

- 推荐练习题目
- 推荐学习资料
- 推荐练习计划

## 四、常见问题

### 4.1 面试相关

**Q: 面试过程中可以暂停吗？**
A: 目前不支持暂停，建议在时间充裕时进行面试。

**Q: 回答时间有限制吗？**
A: 每道题建议在 2-3 分钟内完成回答，超时不会强制结束。

**Q: 可以跳过某道题吗？**
A: 模拟面试模式不支持跳过，自由练习模式可以选择题目。

### 4.2 评估相关

**Q: 评分标准是什么？**
A: 评分从技术正确性、知识深度、逻辑严谨性、岗位匹配度四个维度进行。

**Q: 报告可以下载吗？**
A: 目前支持在线查看，后续版本将支持 PDF 导出。

### 4.3 账号相关

**Q: 忘记密码怎么办？**
A: 点击登录页面的「忘记密码」，通过邮箱重置密码。

**Q: 可以修改用户名吗？**
A: 目前不支持修改用户名，如需修改请联系管理员。

## 五、使用技巧

### 5.1 面试准备

1. **了解岗位要求**：面试前先了解目标岗位的技术要求
2. **复习知识点**：针对岗位要求复习相关知识点
3. **准备项目经历**：整理项目经历，准备用 STAR 法则描述

### 5.2 回答技巧

1. **结构清晰**：先总述再分点详述
2. **突出重点**：先说核心观点，再补充细节
3. **举例说明**：用实际案例支撑观点
4. **承认不足**：不会的问题诚实回答，展示学习能力

### 5.3 提升建议

1. **定期练习**：建议每周至少进行 2-3 次模拟面试
2. **关注反馈**：认真阅读评估报告，针对性改进
3. **追踪成长**：关注成长曲线，持续提升
