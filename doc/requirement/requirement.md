# FaceIt 需求分析文档

## 一、项目背景

### 1.1 问题陈述

随着高校毕业生数量逐年增加，就业市场竞争日益激烈。大学生虽具备专业技能，但在求职面试中普遍面临以下问题：

1. **缺乏真实感练习**：难以获得贴近企业真实流程的模拟面试机会
2. **反馈滞后且主观**：依赖人工指导，反馈不即时、难以量化，且受指导者主观经验影响大
3. **岗位针对性弱**：不同技术岗位（如后端开发、前端工程师、算法工程师）的面试侧重点差异巨大，学生难以针对性准备
4. **综合能力评估不足**：面试不仅考察技术知识，还考察沟通表达、逻辑思维、应变能力等软实力，学生难以全面自我评估

### 1.2 目标用户

- **主要用户**：计算机相关专业大学生（本科、研究生）
- **次要用户**：求职者、职业培训机构

### 1.3 项目目标

开发一个"面向计算机相关专业学生的AI模拟面试与能力提升平台"，核心是构建一个能够模拟不同技术岗位面试场景、并进行多维度智能评估与反馈的AI教练。

### 2.3 核心用例描述

#### UC01：模拟面试

| 项目 | 内容 |
|------|------|
| 用例名称 | 模拟面试 |
| 参与者 | 学生 |
| 前置条件 | 学生已登录系统 |
| 主成功场景 | 1. 学生选择岗位和难度<br>2. 系统生成面试题目序列<br>3. AI面试官依次提问<br>4. 学生回答问题（文字/语音）<br>5. 系统实时分析回答<br>6. AI根据情况进行追问<br>7. 面试结束生成报告 |
| 后置条件 | 面试记录保存，能力档案更新 |
| 异常流程 | 3a. 网络中断：保存当前进度，支持断点续面 |

#### UC02：面试评估

| 项目 | 内容 |
|------|------|
| 用例名称 | 面试评估 |
| 参与者 | 系统（自动执行） |
| 前置条件 | 学生完成一道题目的回答 |
| 主成功场景 | 1. 系统接收学生回答<br>2. 调用大模型分析内容<br>3. 评估技术正确性<br>4. 评估知识深度<br>5. 评估逻辑严谨性<br>6. 评估岗位匹配度<br>7. 生成即时反馈<br>8. 判断是否需要追问 |
| 后置条件 | 评估结果保存 |

## 六、约束条件

### 6.1 技术约束

- 后端使用Java 17 + Spring Boot 3.5
- 前端使用React 18 + TypeScript
- 数据库使用MySQL 8.0
- 向量数据库使用Milvus 2.6
- 缓存使用Redis 7.0

### 6.2 时间约束

- 项目截止日期：2026年4月19日
- 可用开发时间：约28天

### 6.3 资源约束

- 开发团队：5人（1前端+4后端）
- 技术背景：均无agents项目开发经验
