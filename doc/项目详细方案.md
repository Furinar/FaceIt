# FaceIt 项目详细方案

## 一、项目概述

### 1.1 项目背景

随着就业市场竞争日益激烈，求职者在面试前往往缺乏足够的实战演练机会。传统的面试准备方式（刷题、看书、看视频）存在以下问题：

1. **缺乏真实感**：无法模拟真实面试的紧张氛围和即时反应
2. **缺乏针对性**：无法根据个人背景和目标岗位定制面试内容
3. **缺乏反馈**：无法获得专业的面试表现评估和改进建议
4. **成本高昂**：请专业面试官进行模拟面试费用昂贵

### 1.2 项目目标

FaceIt 致力于打造一款 **AI 驱动的智能模拟面试平台**，帮助求职者：

1. **沉浸式面试体验**：通过语音交互模拟真实面试场景
2. **个性化面试内容**：根据目标岗位动态生成面试题目
3. **智能追问机制**：基于回答内容进行深入追问，挖掘技术深度
4. **专业评估报告**：多维度评估面试表现，提供针对性改进建议
5. **能力成长追踪**：记录面试历程，可视化展示能力提升曲线

### 1.3 目标用户

- **应届毕业生**：缺乏面试经验，需要大量练习
- **社招求职者**：希望提升面试技巧，冲击更高薪资
- **转行人员**：需要快速熟悉新岗位的面试要求

### 3.2 AI 模拟面试模块

**功能描述**：模拟真实面试场景，支持语音/文字交互

**核心功能**：
- 岗位选择（Java 后端 / Web 前端）
- 面试模式选择（基础模式 / 全真模式 / 专项训练）
- 面试时长设置（10 / 20 / 30 分钟）
- 语音录制与识别（ASR）
- 文字输入与发送
- 流式对话展示（SSE）
- 面试倒计时与进度条

**面试流程设计**：

```
1. 自我介绍阶段（2-3 分钟）
   ↓
2. 技术提问阶段（主要阶段）
   - 基础知识提问
   - 动态追问（根据回答深入）
   ↓
3. 项目提问阶段
   - 项目经历深挖
   - 技术选型讨论
   ↓
4. 场景题阶段（可选）
   - 系统设计题
   - 问题排查题
   ↓
5. 行为题阶段（可选）
   - 团队协作
   - 问题解决
   ↓
6. 结束面试
```

**技术实现**：
- WebSocket 实时通信
- SSE 流式响应
- MediaRecorder API 语音录制
- 讯飞 ASR 语音识别

**接口设计**：
```
POST /api/v1/interview/create        # 创建面试会话
POST /api/v1/interview/{id}/start    # 开始面试
POST /api/v1/interview/{id}/message  # 发送消息
POST /api/v1/interview/{id}/end      # 结束面试
GET  /api/v1/interview/{id}          # 获取面试详情
GET  /api/v1/interview/{id}/messages # 获取对话历史
GET  /api/v1/interview/history       # 获取历史记录
```

### 3.3 RAG 知识库模块

**功能描述**：构建岗位知识库，支持智能检索

**核心功能**：
- 知识库文档管理（增删改查）
- 文档切片与向量化
- 向量相似度检索
- 混合检索策略（向量 + 关键词）
- 检索结果重排序

**知识库结构**：

```
knowledge_base/
├── java_backend/              # Java 后端知识库
│   ├── tech_stack.md          # 技术栈清单
│   ├── questions/             # 面试题库
│   │   ├── basic.md           # 基础题
│   │   ├── advanced.md        # 进阶题
│   │   └── project.md         # 项目题
│   └── best_answers/          # 优秀回答范例
│       ├── spring.md
│       ├── mysql.md
│       └── redis.md
└── web_frontend/              # Web 前端知识库
    ├── tech_stack.md
    ├── questions/
    └── best_answers/
```

**RAG 检索流程**：

```
1. 用户回答 → 提取关键词
      ↓
2. 向量检索（Milvus）→ Top-10 相似片段
      ↓
3. 关键词检索（BM25）→ Top-10 相关片段
      ↓
4. 混合重排序（RRF）→ Top-5 最终结果
      ↓
5. 构建上下文 → 注入 Prompt
```

**技术实现**：
- LangChain RAG 框架
- Milvus 向量数据库
- OpenAI text-embedding-3 / BGE Embedding
- BM25 关键词检索
- RRF 重排序算法

**接口设计**：
```
POST /api/v1/knowledge/search    # 检索知识库
GET  /api/v1/knowledge/list      # 获取知识库列表
GET  /api/v1/knowledge/{id}      # 获取知识库文档详情
POST /api/v1/knowledge/upload    # 上传知识文档
```

### 3.4 AI 面试官模块

**功能描述**：智能面试官，支持动态追问、多轮对话

**核心功能**：
- 大语言模型调用（智谱 GLM-4）
- 流式响应生成（SSE）
- 动态追问逻辑
- 多轮对话管理
- 面试阶段状态机

**Prompt 模板设计**：

```python
JAVA_BACKEND_INTERVIEWER = """
你是一位资深的 Java 后端面试官，拥有 10 年以上的技术面试经验。
你的任务是对候选人进行专业的技术面试，评估其技术能力、项目经验和综合素质。

面试要求：
1. 根据候选人的回答进行深入追问，挖掘技术细节
2. 关注候选人的逻辑思维和表达能力
3. 模拟真实面试场景，保持专业且友好的态度
4. 每次提问前，先从知识库检索相关内容作为参考

当前面试阶段：{stage}
候选人背景：{user_background}

请根据以下检索到的知识库内容提问：
{rag_context}
"""
```

**动态追问策略**：

```
1. 从回答中提取技术关键词（Spring Boot、Redis、MySQL 等）
      ↓
2. 调用 RAG 检索相关题目
      ↓
3. 构建追问 Prompt
      ↓
4. 调用大模型生成追问
      ↓
5. 追问深度控制（最多追问 3 次）
```

**技术实现**：
- 智谱 GLM-4 API
- LangChain 对话管理
- SSE 流式响应
- Redis 对话历史缓存

**接口设计**：
```
POST /api/v1/ai/chat          # 对话接口（流式响应）
POST /api/v1/ai/evaluate      # 评估接口
```

### 3.5 评估报告模块

**功能描述**：面试表现分析，生成评估报告

**核心功能**：
- 多维度评分（技术正确性、逻辑严谨性、岗位匹配度、表达能力、自信度）
- 逐题点评
- 生成结构化报告
- 雷达图数据生成
- 改进建议生成

**评估维度**：

| 维度 | 权重 | 评估标准 |
| :--- | :--- | :--- |
| 技术正确性 | 30% | 知识点是否准确、是否有明显错误 |
| 逻辑严谨性 | 25% | 表达是否有条理、是否使用 STAR 法则 |
| 岗位匹配度 | 20% | 回答是否契合岗位要求 |
| 表达能力 | 15% | 语速、清晰度、流畅度 |
| 自信度 | 10% | 语气、情感状态 |

**评估流程**：

```
1. 面试结束 → 获取完整对话历史
      ↓
2. 调用 AI 评估引擎
      ↓
3. 多维度评分
      ↓
4. 逐题点评生成
      ↓
5. 改进建议生成
      ↓
6. 存储评估报告
      ↓
7. 更新能力成长记录
      ↓
8. 生成推荐练习
```

**技术实现**：
- 大模型长文本分析
- 结构化 JSON 输出
- PostgreSQL JSONB 存储
- ECharts 雷达图

**接口设计**：
```
POST /api/v1/evaluation/generate  # 生成评估报告
GET  /api/v1/evaluation/{id}      # 获取评估报告
GET  /api/v1/evaluation/{id}/questions  # 获取逐题评价
GET  /api/v1/evaluation/history   # 获取历史报告
```
