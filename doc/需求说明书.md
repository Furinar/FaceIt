1. 首页（欢迎/引导页）

- 平台名称、Slogan（如：AI面试教练，让求职更有底气）
  ​
- 核心功能入口：开始模拟面试、我的面试报告、能力提升、岗位知识库
  ​
- 岗位选择快捷入口：Java后端 / Web前端
  ​
- 平台优势介绍：全真模拟、AI智能评估、多模态交互、个性化提升

2. 用户登录/注册页

- 账号密码登录 / 快捷登录
  ​
- 个人信息：学校、专业、意向岗位、求职阶段
  ​
- 用于保存面试记录、成长数据

3. 岗位选择与面试配置页（核心入口）

- 选择面试岗位：Java后端开发 / Web前端开发（赛题要求至少2个）
  ​
- 面试模式选择：
  ​
- 基础模式（基础题+简单流程）
  ​
- 全真模式（完整企业面试流程+压力追问）
  ​
- 专项训练（技术题/项目题/行为题）
  ​
- 面试时长设置：10分钟 / 20分钟 / 30分钟
  ​
- 显示该岗位面试考点、技术栈、考核维度

4. AI模拟面试室（核心交互页面）

- AI面试官形象/对话窗口（沉浸式界面）
  ​
- 双输入方式：语音输入（自动转文字）+ 文字输入
  ​
- 实时对话展示：AI提问 → 用户回答 → AI即时追问
  ​
- 智能追问逻辑：
  ​
- 抓关键词深挖（如：SpringBoot → 追问原理/项目应用）
  ​
- 回答不完整 → 补充追问
  ​
- 回答模糊 → 压力追问
  ​
- 面试流程控制：自我介绍 → 技术提问 → 项目提问 → 场景题 → 行为题 → 结束
  ​
- 倒计时、中断/重答功能

5. 本地知识库页面（赛题强制要求）

- 分岗位展示：Java后端知识库 / Web前端知识库
  ​
- 内容包含：
  ​
- 岗位核心技术栈清单
  ​
- 高频面试考点总结
  ​
- 面试题型分类
  ​
- 优秀回答范例
  ​
- 技术文档/学习资料
  ​
- 支持搜索检索（RAG底层支撑）

6. 面试评估报告页（核心评分模块）

单场面试完整结构化报告，包含：

1. 基础信息：岗位、时长、面试日期
   ​
2. 总体评分：综合得分、评级（S/A/B/C）
   ​
3. 多维度得分
   ​

- 技术正确性（知识点是否准确）
  ​
- 逻辑严谨性（表达是否有条理）
  ​
- 岗位匹配度（与岗位要求契合度）
  ​
- 表达能力（语速、清晰度、流畅度）
  ​
- 自信度/情感状态（语音情感分析）
  ​

4. 逐题点评：每道回答的优点、错误点、改进方向
   ​
5. 总结分析：优势亮点、薄弱环节、知识漏洞
   ​
6. AI改进建议：具体到知识点/题型/话术

7. 能力提升中心（反馈闭环）

- 根据报告自动推荐：
  ​
- 薄弱知识点学习资料
  ​
- 同类高频面试题强化练习
  ​
- 沟通表达/面试技巧课程
  ​
- 个性化练习计划：按天/按周生成训练任务
  ​
- 错题本/薄弱题专项训练

8. 个人中心 & 成长曲线页

- 历史面试记录：所有报告可回看、重听
  ​
- 可视化成长曲线：综合分数趋势、各维度能力提升趋势
  ​
- 个人能力画像雷达图
  ​
- 账号设置、信息修改

9. 帮助中心/使用指南

- 平台使用教程
  ​
- 面试技巧、求职攻略
  ​
- 常见问题FAQ
