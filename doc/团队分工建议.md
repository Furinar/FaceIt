## 二、协作流程

### 1. 代码协作（Git）

**分支策略**：
```
main          # 主分支（稳定版本）
├── dev       # 开发分支（集成测试）
├── feature/frontend-auth      # 前端认证功能
├── feature/backend-interview  # 后端面试模块
├── feature/rag-knowledge      # RAG 知识库
└── feature/ai-prompt          # AI Prompt 优化
```

**提交规范**：
```
feat: 新增用户登录功能
fix: 修复面试会话创建失败的问题
docs: 更新 API 文档
refactor: 重构 RAG 检索逻辑
test: 添加用户认证测试用例
```

**协作流程**：
1. 从 `dev` 分支创建 `feature/*` 分支
2. 完成功能开发并自测
3. 提交 Pull Request 到 `dev`
4. Code Review 通过后合并
5. 定期将 `dev` 合并到 `main`

### 2. API 协作（Apifox）

**使用流程**：
1. **成员 B** 在 Apifox 中定义所有 API 接口
2. 导入 `/doc/apifox-collection.json` 作为基础
3. 完善每个接口的请求/响应示例
4. **成员 A** 根据 Apifox 定义对接前端
5. **成员 C、D** 根据 Apifox 定义实现后端接口
6. 使用 Apifox 进行接口测试与调试

**接口命名规范**：
```
GET    /api/v1/user/profile          # 获取用户信息
POST   /api/v1/auth/login            # 用户登录
POST   /api/v1/interview/create      # 创建面试会话
GET    /api/v1/knowledge/search      # 搜索知识库
POST   /api/v1/ai/chat               # AI 对话
```
