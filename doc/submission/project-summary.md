# FaceIt 项目概要介绍

## 一、项目简介

### 1.1 项目名称

**FaceIt - AI模拟面试与能力提升平台**

### 1.2 项目背景

随着高校毕业生数量逐年增加，就业市场竞争日益激烈。大学生虽具备专业技能，但在求职面试中普遍面临缺乏经验、紧张怯场、无法精准展现个人能力等问题。传统的就业指导多为一对多的讲座或有限的模拟面试，难以提供个性化、沉浸式、可反复练习的指导服务。

人工智能技术，特别是多模态交互与智能评估技术的发展，为构建高度拟真、反馈及时、个性化定制的面试训练系统提供了可能。

### 1.3 项目目标

开发一个面向计算机相关专业学生的 AI 模拟面试与能力提升平台，通过 AI 技术模拟不同技术岗位面试场景，进行多维度智能评估与反馈，帮助学生提升面试技巧，增强就业竞争力。

---

## 二、核心功能

### 2.1 岗位化题库

- 支持 Java 后端工程师、Web 前端工程师等多种岗位
- 题目类型涵盖技术知识、项目经历、场景设计、行为面试
- 支持难度分级（初级/中级/高级）

### 2.2 智能模拟面试

- AI 面试官模拟真实面试流程
- 支持文字和语音两种输入方式
- 智能追问，模拟真实面试压力

### 2.3 多维度评估

- 技术正确性评估（30%）
- 知识深度评估（25%）
- 逻辑严谨性评估（20%）
- 岗位匹配度评估（25%）

### 2.4 成长追踪

- 面试历史记录
- 能力成长曲线可视化
- 智能推荐练习内容

## 三、技术架构

### 3.1 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | React 18 + TypeScript + Tailwind CSS |
| 后端 | Java 17 + Spring Boot 3.5 |
| 数据库 | MySQL 8.0 + Milvus 2.6 |
| 缓存 | Redis 7.0 |
| AI | 大语言模型 API + RAG |

### 3.2 核心技术

- **RAG（检索增强生成）**：基于向量检索的知识库问答
- **多模态交互**：语音识别 + 文字输入
- **智能评估**：大模型驱动的多维度分析

---

## 四、创新点

### 4.1 技术创新

1. **RAG 增强的面试评估**：结合知识库检索，提供更准确的评估
2. **智能追问机制**：根据回答质量动态生成追问
3. **多模态输入**：支持语音和文字两种输入方式

### 4.2 应用创新

1. **岗位针对性**：不同岗位定制化面试内容和评估标准
2. **即时反馈**：每道题回答后即时获取评估反馈
3. **成长闭环**：评估 → 建议 → 练习 → 再评估的完整闭环
