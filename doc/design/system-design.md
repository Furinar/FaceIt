# FaceIt 系统设计文档

## 一、系统概述

### 1.1 系统定位

FaceIt是一个面向计算机相关专业学生的AI模拟面试与能力提升平台，通过AI技术模拟真实面试场景，提供多维度智能评估与反馈，帮助学生提升面试技巧，增强就业竞争力。

### 1.2 设计原则

1. **模块化设计**：各功能模块高内聚低耦合
2. **可扩展性**：支持新增岗位、题型、评估维度
3. **可维护性**：代码规范、文档完善
4. **用户友好**：界面简洁、交互流畅

## 六、安全设计

### 6.1 认证机制

使用Sa-Token实现JWT认证：
- 登录成功返回Token
- Token有效期：7天
- Token刷新机制：剩余有效期<1天时自动刷新

### 6.2 权限控制

| 角色 | 权限 |
|------|------|
| admin | 所有权限 |
| user | 面试、查看报告、个人中心 |

### 6.3 数据安全

- 密码使用BCrypt加密
- 敏感数据传输使用HTTPS
- 用户数据按用户ID隔离
